Since a rebased PR is welcome: here is a local implementation to compare with.

https://gist.github.com/zqy5618/a1660f500435f9233bc7441518b88af9

`06-sent-outbox-tool.patch` is the outbox: a `list_sent_messages` read view over the journal, returning id, recipient (client + session id), state, sent time and replyTo, newest first. It also covers the case you described — a send whose own answer never came back, where the message is already in the journal.

The same gist has `05-refuse-conflicting-targets.patch` (refuse when `to` and `reply_to` name different sessions; inbound header gains `· sender <sessionId>`) and `02-message-only-session-reads.patch` (message page without token, billing or tool-call history).

All are written against b4fcb0e and not rebased, so they are reference only, not a PR.
